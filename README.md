# 高漫数位板管理面板

在 KDE Plasma 的 Wayland 桌面上配置 GAOMON 1060PRO：选择屏幕和绘图区、调整笔压，并设置笔侧键、板侧键和顶部软快捷键。面板使用系统识别的数位板，无需安装 GAOMON 官方驱动。

> **适用范围：**目前针对 GAOMON 1060PRO 和 KDE Plasma Wayland 开发，并已在 CachyOS 上使用。其他型号、固件或桌面环境尚未验证。

## 开始使用

### 打开已安装的面板

连接数位板，在应用菜单中打开 **“高漫数位板管理面板”**。也可以在终端运行：

```sh
gaomon-manage-panel
```

如果还没有安装，请先阅读[安装说明](docs/DEVELOPMENT.md#安装)。

### 首次设置

1. 确认设备列表中显示你的数位笔；没有显示时，重新连接数位板并点击 **“刷新设备”**。
2. 在“显示器”中选择绘图屏幕，或勾选 **“映射到整个桌面”**。
3. 在两个预览图上调整数位板区域和屏幕区域，然后点击 **“应用”**。
4. 在压感测试区用笔试画，确认能到达所选屏幕的边缘。

屏幕映射和已应用的压感设置会保存。按键绑定需要在面板运行时单独启用，详见[笔与数位板按键](#笔与数位板按键)。

## 屏幕与绘图区

灰色外框表示完整区域，蓝色矩形表示当前映射区域。拖动矩形内部可移动区域，拖动边缘或角点可缩放；也可以用下方百分比输入精确数值。点击 **“恢复整个区域”** 可重置对应的矩形。

如果使用顶部软快捷键，勾选 **“预留软快捷键区域”**，再点击 **“应用”**。此时板面的 100% 指软键下方的绘图区，矩形不会进入软键区。软键位置有按比例的板面预览和上方的放大编号预览。

软键区高度目前按官方布局图估算，实际边界可能因设备或固件而异；如果笔迹或快捷键在边界附近表现异常，请先检查该区域。

## 笔压

1. 点击 **“压感曲线…”**。
2. 拖动曲线上的圆点，或选择 **“柔和”**、**“线性”**、**“偏硬”**。曲线越靠左上，较轻的力度产生的压力越大。
3. 点击 **“应用”**，再在右侧测试区书写。线宽和百分比表示应用收到的压力。

**“恢复默认”**会将曲线和力度范围恢复为设备默认值，点击“应用”后生效。支持力度范围的设备还可调整最低力度和达到最大压力所需的力度；不支持时，这两个控件会禁用，但仍可调整曲线。

## 笔与数位板按键

1. 点击 **“笔与数位板按键…”**，然后点击 **“启用快捷键”** 并完成系统授权。
2. 在对应按键行选择动作：设备默认、键盘快捷键、鼠标左／中／右键或禁用。笔侧键 1 靠近笔尖；板侧键按左右两列分别从上到下编号。
3. 键盘动作在右侧输入组合键；鼠标动作可在右侧添加 Ctrl、Shift、Alt 或 Meta。
4. 点击 **“保存绑定”**。

软键从左到右编号。只有在主面板勾选 **“预留软快捷键区域”** 时才会显示软键；该勾选状态需在主面板点击“应用”后才会影响实际按键处理。

选择默认行为时，右侧会显示设备的原始输出。**“重置所有按键”会立即将笔侧键、板侧键和软键恢复默认并保存。**

按键设置会保留，但快捷键仅在面板运行且已启用时生效。系统托盘可用时，关闭主窗口会将面板隐藏到托盘，已启用的快捷键继续生效；点击托盘图标或选择“显示主窗口”可重新打开面板。选择托盘菜单中的“退出”或点击“停用快捷键”后，数位板恢复系统的默认输入行为。如果系统托盘不可用，关闭主窗口会退出面板。启用快捷键时需要系统授权以访问数位板。

## 常见问题

**找不到数位板？**

确认已经连接 1060PRO，并在 KDE Plasma 的 Wayland 会话中使用。重新插拔后点击“刷新设备”；如果其他数位板驱动正在运行，先关闭它们再试。

**笔无法到达整个屏幕？**

检查选择的显示器及两个预览图中的蓝色矩形。要使用完整绘图区和完整屏幕，分别点击两个区域下方的“恢复整个区域”，然后点击“应用”。如果勾选了软键预留，板面完整区域指软键下方的绘图区。

**软键没有出现或没有反应？**

在主面板勾选“预留软快捷键区域”并点击“应用”，然后打开“笔与数位板按键”，为软键设置动作并启用快捷键。软键默认无动作。

**压力没有变化？**

用数位笔在压感测试区试画，并确认修改曲线后已点击“应用”。绘图程序对压力的使用方式可能不同；如果力度范围不可调，设备仍可使用曲线。

**快捷键停止工作？**

确认面板仍在运行、快捷键已启用，并已完成系统授权。重新启用快捷键后再试；如果鼠标动作在某个应用中没有效果，请在目标应用中单独验证。

## 卸载

如果通过 pacman 安装，可运行：

```sh
pkexec pacman -R gaomon-manage-panel
```

此命令卸载程序；个人设置会保留。通过源码安装的卸载方法见[安装说明](docs/DEVELOPMENT.md#源码安装后的卸载)。
